يدعم تصدير واسترجاع آلاف الصور (Multi-GB Streaming) بدون حدود حجم

1. تصدير وحفظ الصور من الموقع إلى ملف بجهازك

ملف خزنة مشفر (`.vault`) أعلى أماناً

يحفظ جميع الصور، الألبومات، والملاحظات بنظام التدفق المقسم (Chunked Stream) المشفر بـ AES-256 حتى لو كانت 1000+ صورة. لا يمكن فتحه إلا بكلمة مرورك.

أرشيف صور مضغوط (`.zip`) يعمل بكل مكان

يجمع كل صورك الأصلية مقسمة بمجلدات حسب الألبوم مع ملف بياناتها داخل ملف `.zip` قياسي سريع، تگدر تفتحه بأي موبايل أو حاسبة أو ترجعه للموقع لاحقاً.

2. استرجاع الصور إلى الموقع من ملف محفوظ

ارفع ملف (`.vault` أو `.zip` أو `.json`)

يدمج الصور المسترجعة مع خزنتك الحالية بدون مسح الصور الموجودة، وإذا كان ملف `.vault` مشفراً بكلمة مرور مختلفة سيطلبها منك لفك التشفير.

طريقة رفع هذا الموقع على GitHub Pages مجاناً

  1. حمّل ملف هذا التطبيق وسمِّه index.html.
  2. ادخل لحسابك في GitHub وأنشئ مستودع جديد (New Repository) وارفع بداخله ملف index.html.
  3. من إعدادات المستودع (Settings) ادخل لقسم Pages من القائمة الجانبية.
  4. تحت خيار Branch اختر main واضغط Save.
  5. خلال دقيقة سيصبح موقعك جاهزاً على رابطك الخاص، وكل صورة ترفعها تُشفر بـ AES-256 وتنحفظ في متصفحك، وتگدر تحفظها بملف .vault أو .zip وتسترجعها بأي وقت!
